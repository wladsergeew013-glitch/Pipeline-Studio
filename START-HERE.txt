Pipeline Studio 0.7.17

Запустите Pipeline-Studio-0.7.17-x64.exe — переносимое приложение Windows x64.
Для запуска EXE не нужны Python, Node.js или локальный HTTP-хост.
Создайте документ или откройте свой HTML / JSON через стартовый экран.
Открытый HTML редактируется; «Сохранить» записывает его, «Сохранить как» создаёт отдельную копию.
Добавление файла сохраняет настоящий путь. Word, Excel и PowerPoint открываются в системной программе.
Картинки, PDF и видео можно просматривать внутри Studio. Материалы остаются в исходных папках.
Готовый HTML можно смотреть в браузере; для Office и «Показать в Проводнике» запустите EXE один раз.
Перед обновлением закройте прежнюю Studio, запустите новый EXE и пересохраните HTML.
Старое примечание можно преобразовать через «Тип блока» → «Комментарий».
Автономный Pipeline-Studio.html также работает в Chrome или Edge.
Пример: documents/Demo.html.
Двойной щелчок по ячейке — быстрая правка на схеме.
Кнопка «Редактор» над таблицей — продвинутый редактор.
Внизу справа кнопка с глазом — видимость значков блоков.
Меню «Документ» → «Закрыть проект» возвращает к недавним документам.
Подробности: README.md.

0.7.6: родство задаётся у связи отдельно от стрелок. Комментарий следует за подключённым блоком. Симметрия находится у гребёнки и условия. M — рамка выделения, общие свойства — справа. Параметры рисования также справа. Защита от правки снимается в свойствах.
Сохранить пишет открытый HTML; при отсутствии права записи выберите файл при первом сохранении. Для отдельной копии — Сохранить как или Скачать HTML.

В недавних документах показывается известный путь. Открытие папки проекта удалено.
Гребёнка выбирается целиком через любое ответвление. Симметрия — отдельный раздел её свойств; расчёт идёт по подключённым портам.
При выключенном уплотнении независимые ветви сохраняют положение.

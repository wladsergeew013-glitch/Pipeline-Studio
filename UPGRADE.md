# Обновление документа

1. Откройте новый `Pipeline-Studio.html`.
2. Через «Открыть HTML» выберите прежний документ.
3. Сохраните документ через Ctrl+S или «Сохранить как…». В него попадёт обновлённый просмотрщик.

Структура данных остаётся schemaVersion 6. Явно выключенные настройки сохраняются. Для старых документов без флага закрепления относительного положения он включается по умолчанию. Прикреплённые к ячейке материалы сохраняются и показываются компактными значками; название можно включить в инструменте «Ссылка».

Внешние материалы не перемещаются. При переносе сохраните относительную структуру папок.

# Pipeline Studio 0.7.24

Кандидат v0.7.24-rc.1 на основе v0.7.23-rc.1. Использует схему документа версии 6.

- Правый щелчок по блоку или ячейке → «Изолировать ветку». Можно оставить только ветку, приглушить остальную схему или сделать ветку полупрозрачной. Esc восстанавливает предыдущий вид.
- На вкладке «Прогоны» в правой панели явный запуск показывает движение по связям. Настройка уменьшенного движения влияет на работу камеры.
- «Просмотреть в Studio» открывает просмотрщик, «Открыть оригинал» передаёт файл системному приложению. Если исходный путь недоступен, «Выбрать оригинал» открывает выбор файла.
- DOCX отображается в виде текста и таблиц. Для точного воспроизведения оформления доступна PDF-копия.

## Проверка

- Локальные проверки модели, HTTP, Edge и материалов прошли с `tests/run_checks.py --browser --materials`.
- В собранном Windows-приложении проверены открытие и повторное подключение оригинала, просмотр DOCX после замены и PDF в отдельном контексте.
- На чистом профиле переносимый EXE открыл копию РГ 13, показал источник на обзоре, проиграл маршрут при эмуляции уменьшенного движения и сохранил правку в XML. Отдельно проверено движение маркеров в автономном XML в Edge.
- Переносимый EXE прошёл три запуска из новых каталогов. Содержимое приложения совпало с исходниками. Запуск с диска F: подтвердил отрисовку встроенного PDF.

# Pipeline Studio 0.7.16

В сохранённом HTML команда местоположения теперь называется «Показать в Проводнике», как в приложении. Она передаёт подписанный адрес оригинала в установленную Studio с командой выделения файла. Выбор папки проекта для этой операции не нужен. Полный путь и доступ к оригиналу проверяются файловым мостом; неизвестные команды и неподписанные адреса отклоняются.

Перед обновлением закройте прежнюю Studio и запустите EXE 0.7.16. Обычный запуск зарегистрирует новый EXE для ссылок приложения. Пересохраните HTML, чтобы получить исправленную кнопку. На другом компьютере сначала выберите доступные оригиналы в его Studio.

Старые примечания хранятся отдельным типом `note`. Теперь у них доступно поле «Тип блока»: комментарий с загнутым углом, обычный блок или условие. Однородное множественное выделение тоже поддерживает преобразование. ID, текст, оформление, материалы, координаты и соединения сохраняются. Защищённые элементы пропускаются, Ctrl+Z возвращает прежний тип. Документы автоматически не перекрашиваются при открытии.

Проверка на Windows, Python 3.13, Node.js 24 и Edge через Playwright: 661 проверка прошла, одна необязательная проверка LibreOffice пропущена. Включены 172 проверки модели, 8 рабочей схемы, 50 HTTP и локального файлового слоя, 304 браузерные, 77 материалов, 27 файлового моста и 23 packaged-приложения.

Новые регрессии проверяют преобразование одиночных и нескольких примечаний, сохранение данных и связей, отмену, защиту, видимый загнутый угол, кнопку Проводника в реальном сохранённом HTML и передачу точного пути во второй запуск EXE. Дополнительно проверены четыре старых примечания из частной рабочей схемы. В автоматическом тесте системный запуск Проводника и диалоги выбора заменены адаптерами.

Отдельная проверка поставленной portable-оболочки 0.7.16 подтвердила точные координаты всех 127 блоков и отсутствие TCP-слушателя. Настоящий Проводник выделил исходную тестовую картинку: результат подтверждён через Shell COM после повторного запуска и при закрытом редакторе. Использован отдельный профиль, регистрация протокола работающей пользовательской версии сохранена. Проверки 0.7.15 с настоящим оригиналом Word описаны в [отчёте приложения](DESKTOP-2026-10-04.md).

GitHub CI содержит Linux-набор модели и браузера и Windows-сборку portable EXE с проверкой файлового моста и окна приложения. Приватные схемы и локальные отчёты в публикацию не входят. Публичные демонстрационные документы и снимки используют искусственные данные.

# Перенос EXE и файловые команды — 0.7.17

В 0.7.16 команда «Открыть HTML» могла завершиться ошибкой `Error invoking remote method 'studio:file': Error: Команда доступна только редактору Studio` после переноса приложения на другой компьютер.

Ошибка воспроизведена в отдельной копии настоящего portable EXE. Если `TEMP` и `TMP` начинаются с `d:`, Node формирует адрес редактора с `d:`, а Chromium возвращает `D:`. Приложение сравнивало эти адреса как строки и отклоняло команды своего редактора. Проверка обычного запуска на компьютере сборки не покрывала этот случай. Отдельно воспроизведено различие экранирования знака `%` в пути временной папки.

В 0.7.17 адрес декодируется через `fileURLToPath` и сравнивается с точным путём встроенного редактора с учётом регистра Windows. Проверки окна и главного фрейма остаются обязательными. Чужие HTML, дочерние фреймы, HTTP, data и javascript не получают файловый мост. Загрузка редактора использует `loadURL(pathToFileURL(ui).href)`, чтобы корректно передать `%`, кириллицу, пробелы и другие символы пути.

Для переноса достаточно файла `Pipeline-Studio-0.7.17-x64.exe`. Закройте прежнюю Studio, скопируйте новый EXE на другой компьютер и запустите его. Пользовательские HTML и материалы остаются отдельными файлами; пути к исходным материалам должны быть доступны на новом компьютере.

Повторяемые проверки:

```powershell
python tests/run_checks.py
node tests/browser_desktop.js
node tests/browser_portable_transfer.js
```

Последний тест копирует только итоговый portable EXE в отдельную папку `dist` и запускает его с тремя независимыми тестовыми профилями и временными папками: кириллица с пробелами; тот же тип пути с маленькой буквой диска; апостроф, `#` и `%`. Проверяет реальный IPC, кнопку «Открыть HTML», чтение исходника, сохранение и «Сохранить как». Для автоматизации системные диалоги выбора подменяются тестовыми ответами; файловые команды и portable-распаковка выполняются настоящим приложением. Запуск не регистрирует протокол и не использует пользовательский профиль.

Результаты текущего запуска находятся в `qa/portable-transfer.json`, `qa/browser-desktop.json` и `qa/desktop-files.json`. Проверки адреса и отправителя выполняются `tests/test_editor_origin.js`.

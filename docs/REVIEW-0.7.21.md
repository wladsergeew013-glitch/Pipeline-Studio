Защита от правки не фиксирует абсолютные координаты: для положения сохраняется отдельная настройка locked. Для изменения членства защищённой ветви сначала снимается защита. Отклоняется вся соседняя операция, затрагивающая такое членство.

Дополнительно реальная проверка EXE обнаружила обращение к отсутствующему необязательному массиву segments при подсветке общей гребёнки. Подсветка теперь обрабатывает этот вариант без JavaScript-ошибки.

## Результаты

- `python tests/run_checks.py --browser`: **1063 JS-проверки**, **74 Python-теста прошли**, **1 пропуск LibreOffice**. Включены 16 новых VM-сценариев, 2 проверки реального тела native-обработчика и 10 браузерных HTTP/клавиатурных сценариев.
- На исходной базе новый VM-набор проваливал 15 из 16 сценариев, а native-проверка воспроизводила перезапись B поздним A. После исправления все проходят.
- `python tests/test_docker.py`: **2 интеграционные проверки** настоящего образа, слоёв, HTTP и постоянного тома. Все маячки синтетические. При restart тест повторно читает случайно назначенный Docker-порт.
- `node tests/browser_review_desktop.js`: **23 проверки** настоящего Windows-приложения, включая новый native/keyboard/PDF жизненный цикл; ошибок JavaScript нет.
- `node tests/browser_desktop.js`: **23 штатные проверки** настоящего Windows-приложения.
- `node tests/browser_portable_transfer.js`: **3 проверки** локального переносимого EXE в папках с Unicode, разным регистром диска, апострофом, # и %. GitHub Actions проверяется перед публикацией; выбранный публичный EXE дополнительно сверяется с исходным payload и запускается после переноса.
- Для N10/N11 выполнены независимые read-only проверки до и после исправления по `codex-security:fix-finding`; повторная проверка не нашла блокирующих замечаний в этом объёме. Это не общий security-аудит всего репозитория.

Сначала браузерный полный прогон остановился из-за отсутствующего скачанного Playwright Chromium; повтор с установленным Edge прошёл. Первая Docker-попытка задержалась при получении образа; последующий журналируемый build прошёл. Проверка restart выявила смену случайного host-порта, после обновления привязки тест прошёл. Эти причины отделены от результатов продукта.

LibreOffice локально не установлен: настоящий Office→PDF конвертер не запускался; существующие проверки гонок конвертации используют управляемую заглушку. Готовый PDF проверялся реальным просмотрщиком EXE.

Дополнительный свежий запуск EXE с JSON-документом воспроизвёл отмену открытия асинхронной инициализацией стартового экрана. Native-обработчик теперь ожидает готовность редактора до резервирования токена; этот startup-сценарий добавлен в штатный packaged review.

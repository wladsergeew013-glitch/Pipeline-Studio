# Прогоны схем в Pipeline Studio 0.7.23

Вкладки над холстом открывают любой лист документа. Кнопка «Прогоны» открывает панель выбора и воспроизведения сохранённых маршрутов.

1. В редакторе нажмите «Прогоны» и «Новый прогон».
2. Введите короткое название и выберите лист и начальный блок.
3. Отметьте связи для следующего шага и нажмите «Добавить шаг». Несколько связей в одном шаге показывают параллельное движение. Чтобы исправить маршрут, удалите нужный шаг вместе со следующими и продолжите отсюда.
4. Сохраните прогон и нажмите «Запустить». Можно менять скорость, поставить прогон на паузу, перейти на один шаг или сбросить подсветку. «Следовать по схеме» перемещает камеру за текущим шагом.

Команда «Документ» → «XML с прогонами» сохраняет схему, имена прогонов, маршруты и просмотрщик в одном файле. В Edge и Chromium экспортированный XML воспроизводится без сервера. В Studio этот же файл открывается через выбор документа и доступен для редактирования. Документы HTML и JSON тоже хранят настроенные прогоны. Материалы с относительными путями открываются из папки документа.

Прогон следует выбранным связям, включая циклы и параллельные ветви. Если связь или лист удалены, редактор показывает место разрыва. Настройки прогонов записываются в необязательное поле `runs` модели версии 6. HTML и JSON прежних версий открываются с прежней схемой.

## Проверки выпуска

- `tests/test_runs.js` проверяет разветвление, объединение, цикл, направление стрелки, разрыв пути и экранирование XML.
- `tests/browser_runs.js` проверяет прямой переход на лист, одновременное воспроизведение двух ветвей, создание прогона и экспорт с повторным открытием XML без сервера.
- Рабочий процесс `Checks` проверяет модель, HTTP, браузер и Windows EXE.

# Pipeline Studio 0.7.7 — локальная сборка

Отчёт относится к завершённой итерации 0.7.7. Выбранный затем дизайн статусов внедрён в [0.7.8](STATUS-CAPSULES-2026-10-03.md).

Десять задач из плана реализованы или проверены в указанном ниже объёме. Новый внешний вид статусов подготовлен как отдельный дизайн-проект; текущая сборка сохраняет прежнее расположение значков.

## Что изменилось

| Задача | Результат |
| --- | --- |
| 1. Защита и фиксация | Защищённый блок нельзя вручную сдвинуть или изменить. Он следует за родителем и участвует в автоматическом размещении. Только фиксация удерживает его координаты. |
| 2. Выходы условия | Перемещение ветви задаёт симметричный ответ соседней ветви. Горизонтальное и вертикальное движение обратимы; общие продолжения не переносятся дважды. |
| 3. Взаимодействие пайплайнов | Столкновение сдвигает принадлежащие ветви блоки согласованно. Пустые пересечения габаритных областей не запускают перенос. Уплотнение и симметрия рассчитываются до устойчивого положения, чтобы следующий перенос не вызывал дрейф. |
| 4. Гребёнки | Выделенные гребёнки и отдельные связи объединяются через правую панель. Сохраняются все ветви и настройки первой выбранной гребёнки. |
| 5. Четыре связи | У выбранных связей из одного источника появился раздел симметрии: ось, минимальный интервал, разовое выравнивание либо постоянное поведение. Учитываются реальные порты. Фиксированные ветви требуют снять фиксацию перед выравниванием. |
| 6. Ячейка таблицы | Выбор ячейки переключает инспектор на её заливку, текст, контур и выравнивание. Потеря фокуса сохраняет область применения. Есть возврат к таблице и прямое открытие расширенного редактора. |
| 7. Пресеты | Шесть согласованных цветовых тем для блоков, таблиц, ячеек, диапазонов и связей. Общая заливка таблицы видна в ячейках с наследуемым фоном. |
| 8. Копирование свойств | Инструмент слева: заливка, оформление или совместимые поведения. Защита и фиксация включаются отдельной опцией. Источник подсвечивается, повторное применение доступно, Esc завершает работу. Текст, ID, подключения и положение цели сохраняются. |
| 9. Наложение связей | Наведение подсвечивает всю трассу и конечные блоки. Alt + щелчок перебирает совпавшие связи; в панели есть следующая связь. Мостики на пересечениях остаются возможным отдельным улучшением. |
| 10. Материалы | Проверены прикрепление и воспроизведение видео, изображения, сохранение исходников Word/PowerPoint, приложенные PDF-превью и повторное подключение относительных путей после открытия HTML. Исправлена потеря исходного имени локального офисного файла. |

Чтобы применить новую программу к существующей схеме: открыть `Pipeline-Studio.html` этой сборки, нажать «Открыть HTML» и выбрать свой документ. Его собственный встроенный редактор обновится при сохранении из новой программы. Для первого сохранения удобно использовать отдельную копию.

## Проверки

Полный прогон 3 октября 2026 в Edge 154.0.4258.48 завершился успешно: **365 проверок прошли, одна пропущена**.

| Набор | Прошло |
| --- | ---: |
| Публичные проверки модели | 143 |
| Проверки КР/ТХВ на локальной копии рабочего документа | 8 |
| Браузерные сценарии, включая объединение гребёнок ПД в рабочем документе | 178 |
| HTTP и сохранение документа | 25 |
| Материалы: видео, DOCX, PPTX, PDF-превью, PNG, относительные пути | 11 |

КР и ТХВ проверены в обоих направлениях при всех четырёх сочетаниях уплотнения и раздвижения. При отключении обоих режимов ручное наложение допустимо. В остальных проверенных сочетаниях корни ветвей разделены; повторный расчёт после сохранения координат не даёт заметного дрейфа (менее 0,01 px). Проверяется редакция 222 рабочего документа; исходный HTML в Downloads не изменялся.

В браузере отдельно проверены реальное перетаскивание выходов условия, сохранение ячеек и симметрии в автономном HTML, перенос поведения и оформления связи, отмена объединения гребёнок, наведение и выбор совпавших линий. Ошибок JavaScript в браузерных наборах не обнаружено.

Офисные образцы — настоящие синтетические DOCX/PPTX. Браузер сохраняет их с исходным именем и неизменными байтами для открытия внешней программой. Нативный запуск Word/PowerPoint не проверялся. Для просмотра внутри Studio проверено отдельно приложенное PDF-превью. Автоматическая конвертация LibreOffice пропущена: LibreOffice здесь не установлен.

### Повторить

```sh
python tests/run_checks.py --browser
```

Для проверки материалов дополнительно нужны `python-docx`, `python-pptx`, `reportlab`, `Pillow`:

```sh
python tests/run_checks.py --browser --materials
```

`STUDIO_CHROMIUM` задаёт путь к Chromium или Edge. Локальные проверки рабочего документа включаются, если существует `qa/user-document.json`; файл не поставляется и исключён из Git. Без него публичный набор содержит на девять проверок меньше. Отчёты браузера и локальные результаты сохраняются в `qa/`.

## Статусы и сворачивание

Сняты исходные виды блока, условия и таблицы со всеми существующими значками: защита, фиксация, относительное положение, сворачивание цепочки и кнопки продолжений строк. Снимки сняты на искусственной схеме в версии 0.7.6.

Два варианта следующего интерфейса описаны в [дизайн-проекте статусов](STATUS-DESIGN.md). Проверены ширины 736, 360 и 320 px, открытие статусов, независимость настроек, сворачивание цепочек и строк, закрытие по Esc. Макет не меняет рабочую программу.

Эта версия локальная; публичный релиз 0.7.7 не создавался.
